# 🚚 Delivery Dev

Aplicação de delivery desenvolvida com .NET e Blazor, com foco em geolocalização e visualização de pedidos em mapa utilizando Google Maps.

## 🧱 Stack

- .NET / ASP.NET Core  
- Blazor (Server / WebAssembly)  
- Entity Framework Core  
- PostgreSQL  
- RabbitMQ  
- Google Maps API  

## ⚙️ Funcionalidades

- 📍 Visualização de estabelecimentos no mapa  
- 🧭 Geolocalização do usuário  
- 🛒 Simulação de pedidos  
- 🚴 Rastreamento de entregas  
- 🔎 Busca por proximidade
