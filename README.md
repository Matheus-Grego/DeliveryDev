🚚 Delivery Dev
Aplicação de delivery desenvolvida com .NET e Blazor, com integração ao Google Maps para geolocalização e visualização de pedidos em mapa.
🧱 Stack
.NET / ASP.NET Core
Blazor (Server ou WebAssembly)
Entity Framework Core
Google Maps API
RabbitMQ
PostgreSQL
⚙️ Funcionalidades
Visualização de estabelecimentos no mapa
Geolocalização do usuário
Simulação de pedidos
Rastreamento de entrega
Busca por proximidade
